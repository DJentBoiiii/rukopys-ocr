# Результати

## Апаратна конфігурація
- CPU: 4 ядра (без GPU), RAM: 11 GiB
- Python 3.14.5, PyTorch 2.14.0+cpu
- Час нічного прогону: старт 2026-09-25 18:00:54, фініш 2026-09-25 20:37:40
  (загалом ≈2h37m, у межах ліміту `timeout 5h`, заданого в
  `scripts/run_overnight.sh`)

## Етап 1: попереднє навчання (pretrain)
- Датасет: `pumb-ai/synthetic-cyrillic-large`, streaming, перші **15 000**
  прикладів (з ~3.9M, повний датасет не завантажувався)
- Епох: **2**
- Розмір батчу: 16, висота зображення: 32px, ширина: до 384px (padding)
- Час: **47.1 хв**
- Динаміка loss (CTC): епоха 1 → 3.5383, епоха 2 → 2.3251

## Етап 2: донавчання (finetune) на RUKOPYS train
- Джерело: офіційний `train` спліт RUKOPYS (1330 зображень, 21 527
  рядків типу `handwritten` після фільтрації по bbox)
- Використано **6000** прикладів, вибірка зважена на користь `archive`
  (вага x4 відносно інших джерел), розбивка фактично використаних
  прикладів по `source`:

  | source      | n regions used |
  |-------------|-----------------|
  | dictation   | 1924            |
  | school      | 1842            |
  | archive     | 1621            |
  | university  | 613             |
  | **разом**   | **6000**        |

- Епох: **10**
- Час: **97.2 хв**
- Динаміка loss (CTC): епоха 1 → 3.0416 ... епоха 10 → 1.5646

## Загальний час тренування
- Pretrain + finetune: 47.1 + 97.2 = **144.3 хв (≈2.4 год)**
- Оцінка (eval): 210.8 сек (≈3.5 хв)
- Разом (з урахуванням завантаження даних): ≈2h37m

| модель                | WER    | CER    |
|------------------------|--------|--------|
| **власна CRNN+CTC**   | 0.877  | 0.515  |
| Tesseract (ukr)        | н/д*   | н/д*   |

\* Системний пакет `tesseract-ocr` + `tesseract-data-ukr` недоступний у
середовищі виконання (немає прав `sudo` без пароля для встановлення).
Команда встановлення зафіксована в [README.md](../README.md#залежності).
`training/evaluate.py` коректно виявляє відсутність tesseract і пропускає
цю частину порівняння (виводить попередження), решта оцінки виконується
як завжди.

### Розбивка по `source` (власна модель)

| source     | n    | WER    | CER    |
|------------|------|--------|--------|
| dictation  | 3398 | 0.841  | 0.472  |
| archive    | 510  | 0.914  | 0.547  |
| university | 1217 | 0.954  | 0.621  |
| school     | 1248 | 0.890  | 0.496  |

`archive` (документи ЦДАВО, 1919-1935, цільовий домен) показує гірший
результат за `dictation`, що очікувано: почерк і стан документів значно
складніші, а частка `archive` серед фінетюн-даних все ще менша за інші
джерела попри 4х оверсемплінг.

Повний JSON зі всіма метриками: [eval_results.json](eval_results.json).

## Обмеження та подальші кроки

Це перша ітерація на дуже обмежених обчислювальних ресурсах (CPU,
одна ніч, ~2.6 години реального прогону з бюджету 5 годин):

- WER 0.877 / CER 0.515 — далеко не production-якість; модель здатна
  розпізнавати частину символів, але повних рядків правильно майже не
  відтворює
- Використано лише 15k із ~3.9M прикладів synthetic-cyrillic-large
  (<0.4%) та 6k із 21.5k рядків RUKOPYS train (~28%) — обсяг даних
  свідомо занижений заради гарантованого завершення тренування вночі
  на CPU без GPU
- Модель відносно неглибока (CNN + 2-шаровий BiLSTM, hidden=256), щоб
  один крок тренування залишався швидким на CPU
- Порівняння з Tesseract не виконано через відсутність системного
  пакета в середовищі (немає passwordless sudo для встановлення)
- Наступні кроки за наявності GPU/більшого часового бюджету:
  збільшити обсяг synthetic-підмножини та епох претрейну, збільшити
  частку/епохи RUKOPYS train (особливо `archive`), додати аугментації
  (noise, elastic distortion, contrast jitter) для кращої генералізації
  на деградовані архівні скани, спробувати beam-search CTC decode
  замість greedy, і власне встановити Tesseract для чесного порівняння
